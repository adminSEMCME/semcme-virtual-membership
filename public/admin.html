Library content

Follow the steps below to control what members see in each program area.

  1. 1. Choose a program area Select the left-side category members click, such as JEDI or OB/GYN.
  2. 2. Add or edit a library item Choose where it appears: Upcoming, Current, or Archive.
  3. 3. Review the posted list Click an existing item below to edit it, or delete it if it should be removed.
Step 1

Choose or edit a program area

Program areas are the categories in the member sidebar. Most updates only require choosing an existing program here.

Step 2

Add or edit one item

Use this for videos, playlists, registration links, PDFs, or outside resources. Save after each item.

Leave embedding on for public YouTube videos/playlists. Turn it off when YouTube shows “private,” “age restricted,” or “playback disabled”; members will get a clean link instead. YouTube playlists update automatically when videos are added on YouTube.
