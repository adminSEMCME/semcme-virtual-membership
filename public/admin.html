Materials, categories & series

Manage the member library here. Changes appear for members when they reload the page. Assign only confirmed category connections; leave unfinished reviews unchecked.

Need help? Open the admin quick guide

Start in Materials for everyday updates. Save each form before switching tabs.

1. Add or edit

  • Search and select a title, or click Add material.
  • Enter the title, link, and type. Add presenter and date when known.
  • Click Save material and confirm.

2. Choose categories

  • Check every confirmed competency and survey area.
  • Uncheck a category to remove that connection.
  • Leave unfinished review boxes unchecked.

Where materials appear

  • All Materials: every visible material.
  • Category pages: materials assigned to that category.
  • Additional Topics: both reviews complete, with no categories assigned. Only use this when neither group applies.

Group sessions

  1. Create a group in Series & sessions.
  2. Open each material and choose its series.
  3. Set Session order to 1, 2, 3, etc., then save.

Hide or remove

  • Hide: uncheck Include in the updated member library and save.
  • Delete: permanently removes the material and its category connections.
  • Use Categories to rename or hide categories.

Track unfinished work

  • Use the Needs review filter.
  • Internal review notes are for admins only.
  • Members see saved changes after reloading the page.
