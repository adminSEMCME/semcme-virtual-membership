Library content

Follow the steps below to control what members see in each program area.

  1. 1. Review posted items See what is currently live for the selected program area.
  2. 2. Choose a program area Select the left-side category members click, such as JEDI or OB/GYN.

Step 1

Review posted items

This list updates when an item or program is saved. Click an item already in the list to prefill the inputs below with its current details for updating.

Step 2

Choose or edit a program area

Program areas are the categories in the member sidebar. Most updates only require choosing an existing program here.

Step 3

Add or edit one item

Most updates happen here. Use this step to edit existing videos, playlists, registration links, PDFs, or outside resources, or to create a new item. Save after each item.

Leave embedding on for public YouTube videos/playlists. Turn it off when YouTube shows “private,” “age restricted,” or “playback disabled”; members will get a clean link instead. YouTube playlists update automatically when videos are added on YouTube.
